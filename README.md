# AZ-104 Fieldnotes

以繁體中文為主、中英並列的 AZ-104 靜態學習網站。首頁整理六條 Microsoft Learn 學習路徑與各自的小主題骨架；身分識別與治理中的 Azure RBAC 與權限範圍，提供第一份完整筆記和互動練習。

## 六大學習路徑

1. Azure 系統管理員的先決條件
2. 管理身分識別和治理
3. 設定及管理虛擬網路
4. 實作和管理儲存體
5. 部署和管理 Azure 計算資源
6. 監視和備份 Azure 資源

首頁的小主題是學習導覽骨架，不代表完整或官方考試範圍；實際考試目標請以最新 Microsoft Learn AZ-104 study guide 為準。各路徑卡片提供對應官方 Learn 連結。

## 本機預覽

直接以瀏覽器開啟 `index.html` 即可，無需安裝依賴或啟動後端。

## GitHub Pages

在 repository 的 Settings > Pages 選擇部署來源分支與根目錄。網站使用相對路徑，可由 repository 根目錄發布。
